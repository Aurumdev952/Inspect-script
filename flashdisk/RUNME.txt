PC INSPECTION - HOW TO USE
==========================

ONE-TIME SETUP (on your own PC):
  1. Unzip the release zip and copy the ONE folder "PC-Inspection" onto
     the flash disk (anywhere - everything needed is inside it).
  2. Open config.json in Notepad and fill in:
       - WebhookUrl   : the Google Apps Script URL (from the team)
       - WifiNetworks : Wi-Fi name + password (you can list several)
       - DriverPackages: download links for network drivers (optional)
  3. (Optional) Put driver folders with .inf files in drivers\

ON EACH PC:
  1. Plug in the flash disk and open the PC-Inspection folder.
  2. Double-click PC-Inspection.exe  (click "Yes" on the admin prompt)
     (or PC-Inspection.bat - same thing, use it if the exe is blocked)
  3. When it says "You can REMOVE THE FLASH DISK now", pick your name
     from the list (Enter = last used), then take the flash disk out and
     go to the next PC - this PC keeps going on its own.
  4. Come back later for the PASS / FAIL result, then press Enter.

  The tool: installs missing network drivers, adds the Wi-Fi and connects,
  checks CPU / RAM / disk / Windows activation, then uploads the result.
  Results: uploaded to the Google Sheet, saved on the PC in
  C:\ProgramData\PC-Inspection\inspection-log.csv, and copied to the
  flash disk too if it is still plugged in at the end.

WHY IT DOES NOT START BY ITSELF WHEN I PLUG THE FLASH DISK:
  Windows (7, 10, 11) blocks auto-run from USB flash disks on purpose - it
  is how USB viruses used to spread. You must double-click
  PC-Inspection.exe.

IF PC-Inspection.exe SHOWS 0 KB OR DISAPPEARS:
  Windows Defender removed it by mistake (false alarm - the exe is not
  code-signed). Open Windows Security -> Virus & threat protection ->
  Protection history -> pick the item -> Actions -> Allow / Restore.
  Or use the backup: double-click PC-Inspection.bat (does the same thing).

IF WINDOWS SAYS "Windows protected your PC":
  Click "More info" -> "Run anyway". (The exe is not code-signed.)

LOGS (for debugging):
  Every run is logged in C:\ProgramData\PC-Inspection\logs on that PC and,
  if the flash disk is still plugged in at the end, in the logs folder on
  the flash disk (logs\usage-log.csv lists every run of every PC).
  Flash disk removed early? Plug it in again on that PC and double-click
  COLLECT-LOGS.bat. When something looks wrong, send the logs folder.
